# default

Stock QMK layout — no Vial, no WebGUI colors, no SignalRGB. Base QWERTY layer
plus one Fn layer (symbols/F-keys/navigation), stock RGB Matrix animations,
`QK_BOOT` on the Fn layer for bootloader entry.

See the `vial` keymap for VIA/Vial support, or `keyColors` for the WebGUI
per-key color engine + keypeek integration.
